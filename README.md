# 📚 Diario de Estudio (Study Tracker)

A lightweight web application designed to track study sessions, monitor daily streaks, and display study progress using an interactive GitHub-style contribution heat map.

🚀 **Live Demo:** [jonathancast13.github.io/diario-de-estudio](https://jonathancast13.github.io/diario-de-estudio/)

---

## ✨ Features

- ⏱️ **Session Tracking:** Log study time and track learning progress effectively.
- 🔥 **Streak Counters:** Stay motivated by monitoring daily active study streaks.
- 📊 **GitHub-Style Heat Map:** Visual overview of study frequency and consistency over time.
- 💾 **Local Persistence:** Retains session history directly in the browser.

---

## 🛠️ Built With

- **HTML5** - Semantic markup structure.
- **CSS3** - Custom styling and visual layout.
- **JavaScript (ES6+)** - Core logic, DOM manipulation, and dynamic heat map rendering.
